# Rubric — A1: Template Build
**50 points · Assessed against CO1**

> CO1 — *Draw storyboards as a planning tool for their visual narratives.*

Fifty points for a rectangle with the right proportions. Take the free points, then never think about it again — you will use this file for the rest of the term.

---

| Component | Pts | Full credit |
|---|--:|---|
| **Aspect ratio, correct** | 20 | Panel proportions match the assigned ratio within 1%. Arithmetic is shown or the file is measurably correct. |
| **Template fields** | 15 | Every panel carries space for: panel/shot number, shot size and angle, action description, camera notation. Nothing is missing and nothing is decorative. |
| **File delivery** | 10 | Layered `.psd` (or `.psd`-compatible) **and** a flattened export at the correct pixel dimensions. Both files named per the convention in H1. |
| **Craft** | 5 | Panels aligned, guides consistent, page prints cleanly. |

**Total: 50**

---

## Grading notes

**This is not a drawing assignment.** Nothing here is graded on rendering. It is graded on whether the document is correct and usable, which is exactly the standard applied to a production document.

**Why the ratio matters more than it looks like it does.** If your template is the wrong shape, every panel you draw this month is composed for a frame that doesn't exist. Every headroom decision, every leadroom decision, every edge relationship — all of it recalculated the moment the ratio changes. That's why this is assignment one.

**Show the arithmetic.** Frame height × ratio = frame width. 4″ × 1.85 = 7.4″. If the proportions are wrong, partial credit is available where the working is visible and the error is arithmetic rather than conceptual.

---

## Common failures

| Failure | Cost |
|---|---|
| Panel is "about right" but not measured | Up to 20 |
| No layered file, export only | Up to 10 |
| Template has no room for camera notation | Up to 5 of the fields score |
| Correct ratio, wrong orientation | Full ratio deduction — check which number is width |

---

## Milestone note

A1 is a single-stage assignment and carries no milestone cap. It is, however, a **prerequisite** for the City Park sequence: boards submitted on a template that was never graded are boards on an unverified ratio, and they will be assessed as such.
