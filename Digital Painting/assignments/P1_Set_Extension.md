# P1: The Set Extension

**Digital Painting · briefed class 4 · final due at the start of class 8**

---

## Where the tiers sit

Read this part first, and decide before you start which line you are aiming at.
Every project in this course states three of them, and the one you pick is a real
choice rather than a polite fiction.

| Tier | What you deliver |
|---|---|
| **Baseline** | One composited image, at least four separate photographic sources, no visible seams, values that agree. Reachable on a lab machine with a mouse in the studio hours you already have. |
| **Target** | The same image, plus a stated light direction and a stated camera, held consistently across every element in the frame. This is what the rubric is written around and what the critique will discuss. |
| **Extension** | A second version of the same painting at a different time of day, sharing the identical geometry. Everything moves except the architecture. |

Extension work is never graded against the Target underneath it. If you reach and it
does not land, you are assessed on the Target. Reaching is free here, which is the
only way anyone actually does it.

---

## The job

A set extension is the oldest working job in this line of work, and it has not
changed much since a painter stood at an easel in front of a camera with a sheet of
glass. Somebody shoots a plate. The plate contains a real place, and the real place
stops short of what the story needs. Perhaps the wall is only twelve feet high and
the shot wants a cathedral. Perhaps the parking lot is a parking lot and the shot
wants a harbor. Your job is to extend the frame so that a viewer never asks where
the photograph ended.

That last clause is the whole assignment. Not "so the painting looks nice." A set
extension that looks nice and reads as a painting has failed at the only thing it
was hired to do.

You will be given a base plate and a source folder. You may bring your own material
(see EX4, and see the sourcing rules below), but you are not required to, because
four class days is not enough time to also go find a photograph of a harbor.

---

## Deliverables

Everything goes in one folder named `Lastname_P1`.

1. **`Lastname_P1_final.jpg`**, at the resolution of the provided plate, no smaller.
2. **`Lastname_P1_working.psd`**, layered, grouped, and named. The working file is
   graded. A flattened PSD is not a working file, it is a JPEG with extra steps.
3. **`Lastname_P1_sources.md`**, a plain list: every image you used, where it came
   from, and what license it carries. Three columns, no prose required. Anything
   generated gets listed here too, with the tool and the prompt.
4. **`Lastname_P1_wip.jpg`**, a contact sheet of three stages: blockout, rough,
   final. Screenshots are fine. This exists so the critique can talk about decisions
   rather than only about outcomes.
5. **Extension tier only:** `Lastname_P1_alt.jpg`, the second time of day.

## Milestones, and what they are for

| Due | What | Why it is a milestone |
|---|---|---|
| Class 6 | Blockout | Big shapes, correct perspective, no detail. If the perspective is wrong here, it is wrong in the final, and it is cheap to fix now and expensive to fix later. |
| Class 7 | Rough | All elements in place, values matched, edges unresolved. This is the last point where a bad decision can be reversed without starting over. |
| Class 8 | Final | Critique. |

The milestones are not busywork and they are not separately weighted much. They
exist because the single most common way this project fails is a student spending
six hours rendering a beautiful building that sits at the wrong horizon line.

## What "no visible seams" actually means

Some of these include, and none of this list is complete:

- **Value agreement.** Squint at the image, or drop a black-and-white adjustment
  layer on top. Elements shot in different light will separate immediately, and they
  separate in value long before they separate in color. Fix value first, always.
- **One light direction.** Pick it, write it down, and check every element against
  it. A building lit from the left next to a tree lit from the right is the loudest
  error available and the one students see last.
- **Atmosphere with distance.** Things further away get lighter, lower in contrast,
  and cooler, or warmer, depending on the air. Pick one behavior and apply it
  consistently. This single adjustment does more for believability than any amount
  of detail.
- **Edge quality.** A hard cut-out edge against a soft photographic background is a
  seam even when the color is perfect. Match the softness, match the focus, match
  the grain.
- **Grain and noise, last.** Every source has a different grain structure. A final
  unifying grain pass over everything is the cheapest trick in the trade and it
  covers a surprising amount of sin.

## Sourcing and provenance

Use whatever you like, and write down where it came from. That is the entire rule,
and it is a professional habit rather than an academic one: a studio that cannot
prove where an element came from cannot deliver the shot.

Generated material is permitted at every tier and required at none. If you use it,
it goes in the sources file like anything else, with the tool named and the prompt
recorded. A generated element is treated exactly like a stock photograph here: it is
a source, it has to be integrated, and it will be judged on whether it integrated.

If you would rather not use generative tools at all, nothing in this project asks
you to, and no tier is closed to you.

## Rubric

Totals 100% of this assignment.

| | Weight | What earns it |
|---|--:|---|
| **Value and light integration** | 30% | Elements agree in value. One light direction, held. Atmospheric behavior consistent with distance. |
| **Edge and seam control** | 20% | No cut-out edges. Focus and softness matched to depth. Grain unified. |
| **Perspective and scale** | 20% | Horizon consistent. Scale reads. The added architecture sits in the same space as the plate. |
| **File craft** | 15% | Layered, grouped, named, non-destructive. Somebody else could open it and work. |
| **Provenance and process** | 15% | Sources file complete and honest. Contact sheet shows three real stages. |

Nothing here is graded on drawing ability, and nothing here requires a tablet.

## What usually goes wrong

**Starting with the sky.** The sky is the easiest thing to place and the least
important. Start with the thing the shot is about.

**Rendering before blocking.** A detailed element in the wrong position is a loss.
Move everything into place badly first, then improve it.

**Matching color instead of value.** Students reach for the hue slider. The eye is
reading the brightness relationship, and it reads it first.

**Never squinting.** Squint at the screen, or turn the image to grayscale, or stand
up and walk six feet back. All three do the same thing, which is to strip detail and
show you the structure underneath. Do it every twenty minutes.

**Stopping too late.** More detail is not more believable. This comes back in class
7 and it is worth waiting for.

## A note on the Extension tier

The second time of day is harder than it sounds and it is the single most useful
thing in this project for a portfolio, because it demonstrates something a still
image cannot: that you understood the scene as a place with a light source rather
than as an arrangement of photographs. Anybody hiring for this work knows the
difference on sight.

If you take it on, do the Target version completely first. The alternate version is
built from the finished file, not alongside it.
